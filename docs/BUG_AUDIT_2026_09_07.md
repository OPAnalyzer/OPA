# Local bug audit — 2026-09-07

Scope: local OPA 2.46.0, with corrections released as 2.46.1. The local
branch was six commits behind its existing origin/main tracking reference;
this audit does not certify those newer commits.

## Confirmed defects corrected

- A synthetic station opposite a GEO slot received five false Sun-transit
  events despite Earth blocking its line of sight. Reject below-horizon slots.
- Explicitly empty candidate dates silently invoked the default year search.
  Empty input now raises a validation error.
- Changed Sun-outage inputs left an exportable old result. Clear the result
  and cancel the pending job on input, station or profile changes.
- A queued completion could repopulate results after logout/cancellation.
  Invalidate acceptance before clearing session data and ignore late delivery.
- The Azerbaijani Settings precision row squeezed the absolute-tolerance
  editor. Stack the fields vertically.

## Completed checks

- Baseline: 130 unittest tests passed.
- Extended suite: 132 tests passed, covering numerical modules, admin package
  verification, persistence/restart, navigation, themes and layout.
- Live-timer manual SRP stress: 3,000 edits over 65 seconds, exit code zero,
  window still visible at completion.
- Compilation, public-content scan and whitespace validation passed.
- Offscreen visual captures cover Normal/Retro, English/Azerbaijani,
  Settings/admin, telemetry and Eclipse at laptop/desktop dimensions.
- Repeated capture runs passed at Qt scale factors 1, 1.25, 1.5 and 2
  (28 images). Representative Settings and Retro admin captures were inspected.
- After the precision-field layout correction, all 9 layout/restart tests
  passed. The final offscreen public launch smoke test also passed.

## Limits and follow-up

- Offscreen Qt scaling checks do not replace interactive testing on physical
  Windows displays, GPU drivers and a long-running operator session.
- Admin tests use a signed synthetic package and a test device protector;
  no real private package was unlocked during this audit.
- Sun-outage predictions use state-derived inclined/eccentric periodic GEO
  geometry when the active profile supplies a valid J2000 state, with the
  fixed nominal slot retained as a labelled fallback. The equinox search
  window and daily bounded minimum remain; wide-beam and UTC-midnight transit
  cases require additional scientific validation before global use.
- No remote push or merge was performed.
